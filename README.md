## Features

* **Interactive Progress Tracking:** Checkable task rows that automatically calculate completed events, total playlist points, and reward unlock status with persistent browser storage (`localStorage`).
* **Verified Community Tunes:** Recommended tunes and share codes ordered by trusted creator priority, complete with one-click copy buttons.
* **Full Event Specifications:** Detailed car class restrictions, race disciplines (Road, Street, Dirt, Cross Country), and specific course types (Circuit, Sprint, Scramble, Trail).
* **Search & Filters:** Real-time filtering by category (Championships, PR Stunts, Challenges, Horizon Play) and live keyword search across events and cars.
* **Dual Formats:** Hosted responsive HTML dashboards alongside lightweight plain-text (`.txt`) companion summaries for quick reference.
